# hunyuan2.1++

HiCache++ — DMD/Prony EXPONENTIAL velocity forecasting (the new method) on Hunyuan3D-2.1, with HiCache (Hermite) kept as the comparison baseline. A diffusion feature trajectory solves a near-linear feature-ODE whose exact class is a sum of exponentials, not polynomials, so the DMD basis stays lossless at larger skip intervals than HiCache's polynomial. See `hicache-plus-plus` for the standalone library.
